### Appointments_Calendar
A simple Windows Appointments Application built just for fun. The AppointmentsList.txt file is not protected, and is not encoded; handle with care.
To run the application:
 - Download Zip file
 - Extract project
 - Open the whole project folder on your IDE (Project built with IntelliJ IDEA, not tested on other IDEs)
 - Run Main class
 - Check Appointments_Calendar_Pics...
